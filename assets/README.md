# Assets 目录

这个目录用于存放应用的静态资源文件：

- `icon.png` - 应用图标 (1024x1024px)
- `splash.png` - 启动画面图片
- `adaptive-icon.png` - Android自适应图标
- `favicon.png` - Web端图标

## 如何添加资源

1. 准备符合尺寸要求的图片文件
2. 将文件放入此目录
3. 确保文件名与 `app.json` 中的配置一致

## 资源要求

- **icon.png**: 1024x1024px, PNG格式
- **splash.png**: 推荐 1242x2436px (iPhone) 或 1280x1920px (Android)
- **adaptive-icon.png**: 1024x1024px, PNG格式，前景图
- **favicon.png**: 48x48px 或更大, PNG格式
